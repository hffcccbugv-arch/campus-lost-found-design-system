# Wireframes

Low-fidelity wireframes for the two proof pages, drawn before the checks in the documentation, at 320 px and 1400 px. They were drawn with an AI assistant (Instinct) at the student's request from the built pages, so they describe the final layout and are not the first sketch.

- index-wireframe.svg: items page
- report-wireframe.svg: report form page

Each region is labelled with the grid span and the component or token it uses.
